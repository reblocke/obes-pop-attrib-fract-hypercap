# Obesity and Hypercapnic Respiratory Failure PAF Analysis

This repository contains a Quarto/R analysis of obesity, BMI, hypercapnia, and hypercapnic respiratory failure (HRF) using a TriNetX-derived encounter dataset.

The canonical report is:

```text
reports/obesity_hrf_paf_analysis.qmd
```

An archival reconstruction of the earlier rendered PDF is retained for comparison:

```text
reports/reconstructed_obesity_hrf_from_pdf.qmd
```

## Data

The source dataset is expected to be generated by the upstream TriNetX preprocessing repository:

```text
https://github.com/reblocke/trinetx-preprocessing
```

Place the local restricted data file at:

```text
data/raw/full_db.rds
```

The raw data directory is ignored by Git. Do not commit `full_db.rds`, derived raw extracts, PHI, restricted data, or machine-specific paths.

## Local Setup

Run commands from the repository root.

There is currently no committed `renv.lock`. Use the packages already available in the local R library for the first render. If the maintainer decides to lock the environment, use:

```bash
make renv-init
```

This manual target installs `renv` if it is missing, then initializes and snapshots the project library.

Do not add `install.packages()` calls to committed `.qmd` or `.R` files.

## Render

Render the main report in all configured formats, including PDF:

```bash
make render
```

Render only the HTML report for quick local checks:

```bash
make render-html
```

Render only the PDF report:

```bash
make render-pdf
```

Render the archival reconstruction only if needed:

```bash
make render-archival
```

If no tests have been added yet, `make test` will report that no `tests/testthat` directory exists.

## Expected Checks

After rendering, confirm that the report shows source dataset size, BMI and gas-pair missingness, attrition, respiratory-status counts, baseline characteristics, BMI-category HRF plots, primary and sensitivity logistic models, the hypercapnia subgroup model, the named PIF table, the BMI-risk curve, and PDF output.
